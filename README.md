# LlamaIndex Tutorial in Tamil 🐪

Welcome to the **LlamaIndex Tamil Tutorial Series**! This repository contains code, examples, and resources for learning about **LlamaIndex, AI indexing, embeddings, and vector search**, all explained in Tamil.

## 📌 What You'll Learn
- Introduction to AI and Information Retrieval
- Understanding Indexing and Vector Search
- How LlamaIndex Works
- Hands-on Implementation
- Vector Storage with PostgreSQL and Redis
- Knowledge Graph Storage with Neo4j

## 🚀 Getting Started
### 1️⃣ Clone the Repository
```bash
 git clone https://github.com/yourusername/llamaindex-tamil-tutorial.git
 cd llamaindex-tamil-tutorial
```
### 2️⃣ Install Dependencies
```bash
pip install llama-index openai pandas numpy
pip install -U sentence-transformers
pip install --upgrade typing_extensions
pip install llama_index
pip install llama-index-graph-stores-neo4j  # For Neo4j graph storage tutorial
pip install neo4j python-dotenv  # Additional Neo4j dependencies
```

## 📚 Tutorials Available

This repository contains the following tutorials:

### Vector Storage Tutorials
- **`storing_data_into_pgvector.ipynb`** - Learn how to store and query vectors using PostgreSQL with pgvector extension
- **`redisvector-demo.ipynb`** - Demonstrate vector storage and retrieval using Redis

### Graph Storage Tutorials  
- **`neo4j_graph_storage_tutorial.ipynb`** - Complete guide to using Neo4j for knowledge graph storage with LlamaIndex

### Core LlamaIndex Tutorials
- **`Introduction_vector_embeddings.ipynb`** - Introduction to vector embeddings and their applications
- **`LlamaIndex_BioBERT_Embeddings.ipynb`** - Using BioBERT embeddings for domain-specific applications
- **`LlamaIndex_Prompts_Loading_Ingestingdata.ipynb`** - Learn about prompts and data ingestion
- **`creating_index_retrievers_metadatafilters_chatbot_with_advanced_features.ipynb`** - Advanced chatbot features with metadata filtering
- **`tamilpdf_extraction.ipynb`** - Extract and process Tamil PDF documents

## 🎯 Getting Started

Choose the tutorial that matches your learning goals:
- **New to LlamaIndex?** Start with `Introduction_vector_embeddings.ipynb`
- **Want to store vectors?** Try `storing_data_into_pgvector.ipynb` or `redisvector-demo.ipynb`  
- **Interested in knowledge graphs?** Check out `neo4j_graph_storage_tutorial.ipynb`
- **Working with domain-specific data?** Look at `LlamaIndex_BioBERT_Embeddings.ipynb`
